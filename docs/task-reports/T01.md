## 实测步骤与结果

使用旧 `p2p_file` 的临时身份、两行服务/两行客户端配置、动态 loopback 管理端口和合成 token，在真实浏览器 IAB 中操作。

| 场景 | 旧基线 | 修复版本 |
| --- | --- | --- |
| 服务第一行名称改为带前后空格的中文草稿，取消启用，新增第三行 | 名称恢复 echo、启用恢复 true，编辑丢失 | 原始文本（含空白）和 false 保留；删除第三行也保持 |
| 客户端第一行改名，启用和自动启动均 false，删除另一行 | 名称恢复 a、两个复选框恢复 true | 增加/删除第三行均保持全部编辑 |
| 服务全部禁用后保存失败 | 不作为旧结构丢失的替代证据 | 错误显示、草稿不丢；开启首行后保存成功并规范化名称 |
| 客户端另一行写非法监听后保存失败 | 同上 | 其他行名称/启用/自动启动保持；修正监听后成功保存 |
| 保存后再编辑，主动“加载” | 不作为结构操作 | 明确放弃草稿，恢复实际持久值 |
