## 实现

新增 node/control：复用现有 NodeSessionHandle 和 TransferService，提供 NodeCommand、NodeSnapshot、带序号的有界广播、同锁订阅点/快照及文件投影读取。快照从有类型 SessionEvent 投影，拒绝旧 peer 代际，保留授权来源的入站/出站密码和可信设备标记；容量不足明确 truncated，不把缺失项当成功。

桌面网络字段改为 NodeControl，启动走 control::spawn，命令仍委托现有状态机，原有界细节事件通过 ControlEvents 交给现有界面。核心线程改名 p2p-node-network。新增显式 spawn_with_storage 供无 GUI 宿主创建任务库和文件服务；提供自动恢复、限速、接收根/安全余量、已完成历史管理及安全文件定位入口。

纯领域 Snapshot/TaskDetail/Diagnostics 类型可公开复用；核心不含 GPUI 导入或 desktop 反向依赖。网络事件序号与文件 checkpoint 分开，不从“命令已提交”推导“文件完成”。当前保留内嵌桌面，正式后台/IPC 在 T24/T30 实现。
