## 迁移

将 config、remote_auth、trusted_devices、protocol、task_model、task_store、task_recovery、task_events、bandwidth、instance_lock 的实际实现移到 node，原 desktop 文件仅重导出；不是复制第二份实现。任务库依赖实例锁，因此实例锁从原 T14 提前至 T12 并同步修订精确清单。

BackgroundOptions 仅持久化数据形状移入 preferences，平台窗口行为仍在 desktop；接收安全余量常量/校验移入 receive_policy，避免核心反向引用文件服务或 GUI。新增默认 node 特性，gui 依赖 node；无 GUI 核心只启用认证、存储与路径依赖。保留原有 staged 模型/恢复 API 的 dead_code 限定许可，未放宽 clippy 其他错误。

线格式、认证上下文、枚举和 schema 未改，桌面设置仍为 schema 11，任务存储仍为 format 1。原模型测试移动且只改模块引用；此轮未运行，不把移动等同兼容验证。
