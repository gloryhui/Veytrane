## 实现

按 `docs/specs/NODE_SIGNAL_LIFECYCLE.md`，新增无 GUI 的信令 worker，独占原 SignalingClient 并在失联时释放旧 reader/writer，以原身份、TLS 配置及现有网络候选退避重登。事件队列有界，携带代际并丢弃旧代积压消息。worker 随所有者 Drop 取消。

serve_session 的信令错误不再退出业务会话；后台通道关闭只停用该分支并记录一次诊断，避免空转。现有 Direct/Relay 连接、空闲重打洞和权限检查仍由原业务所有者管理；重登后主动查询原 peer 取得新 pairing，不重新分配 UDP/QUIC 网络。未修改线上消息、版本、认证或授权策略。
