# T31：停机导入与防误建身份

实现路径：`node/migration.rs`；CLI `migrate-preview` / `migrate-desktop --expected-preview HASH` / `migrate-resume --expected-preview HASH`。只导入旧桌面schema1..11，旧CLI规则/文件策略没有等价适配时明确拒绝，不转换成备份发布策略。

预览与执行均取得源实例锁、源任务锁、目标目录锁及NodeId身份锁；活的旧所有者不得被杀掉或绕过。预览从有界只读字节解析旧配置与任务，不运行TaskStore启动恢复。输出NodeId、已知peer/任务数量、文件策略、权限收紧范围和源指纹；不输出私钥/验证器/绝对业务路径。执行必须重算并匹配预览指纹，源变化拒绝。

目标身份/配置/任务均不存在才可开始。先写私有`.migration-backup-*`，保存源身份、源配置、原始任务及生成的node.json；保留原有receive_root和任务绝对绑定、取消状态、回执，不移动业务文件或stage。源不删除。已知peer设置显式LegacyDesktopV1，信任来源LegacyImport，文件/测速资源仅已知peer；不把密码认证开放给未知旧协议peer。新peer必须显式选模式/授权，不能声称未知旧端自动互通。

目标`migration.pending.json`记录备份目录名、源指纹和各目标摘要，路径只允许本目录单组件。身份使用无覆盖原子发布，任务原始字节使用原子替换，配置根最后写。中途失败保留pending和备份，宿主拒绝启动，不自动生成身份。显式resume只补不存在的目标；存在目标必须与备份精确一致，任何变化拒绝，尤其不覆盖迁移后新任务/授权。完成后删除pending；不提供自动恢复旧权限的回滚命令。

默认用户目录检测到旧桌面身份时，首次init/initialize拒绝另建身份并提示先预览导入。自选独立目录用于用户明确创建另一个节点，不能自动替代旧身份。导入工具在CLI执行；原生管理窗口不读取旧私钥或解析迁移CLI输出。

所有真实导入、崩溃点及文件冲突回归后置，本轮只静态检查；不得用用户在用数据试运行。
