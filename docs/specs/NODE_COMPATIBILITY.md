# 当前协议实现边界

2026-10-21：只维护当前用户使用的版本，不承诺历史客户端兼容。以下是源码实际调用边界；清理记录见 [LEGACY_CLEANUP](../task-reports/LEGACY_CLEANUP.md)。

| 路径 | 当前实现 | 约束 |
| --- | --- | --- |
| UnifiedV1 | 当前 Agent、Sub2API 默认协商；文件、测速、服务 ID 与 TCP 分发 | 文件与测速逐 peer 授权；方向与资源分别检查。 |
| LegacyDesktopV1 | 核心仍有 P2PD/P2PA 执行分支，独立核心会话及真实进程回归仍使用 | 不因旧能力位放宽权限；每条流检查当前策略，裸目标按精确 ACL。内嵌旧桌面程序已退役。 |
| 独立 CLI | src/main.rs 的现有传输、隧道和服务命令使用独立线格式 | 不能宣称与 Agent 协议互通，身份锁仍与 Agent 共用。 |

未实现的 `LegacyCliV3` 占位模式已从枚举和会话分支删除，配置 JSON 直接拒绝。没有协议试错探测或认证失败降级。

旧桌面数据导入和 schema 1–10 自动升级已删除。`TrustSource::LegacyImport` 仅保留已有授权记录的来源信息，不把它改成密码验证证明，也不重新生成授权；新管理员预置信任仍标为 Administrator。当前 node.json 和任务持久格式保持不变。

`LegacyDesktopV1` 与通用文件 codec 尚有实际耦合，后续若移除，需要同时转换独立核心调用、流分发和文件恢复回归；不能按名字删除共用实现。本文记录现状，不把源码保留或本机回归当作旧二进制互通验收。
