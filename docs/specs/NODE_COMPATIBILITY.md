| 模式 | 本次实现范围 | 约束 |
| --- | --- | --- |
| UnifiedV1 | 新节点基础协商、资源授权、文件/测速/服务 ID/TCP | Agent 默认；文件与测速逐 peer 授权；方向与资源分别检查 |

没有协议试错探测或认证失败降级。兼容构造器仅供过渡旧桌面，正式 Agent 使用 Unified 默认，并在同一个所有者内逐 peer 显式选择旧桌面。若运行原独立 CLI，身份锁必须与 Agent 共用；有 Agent 时不绕过它再登记。

新 Agent 的文件/测速资源策略对显式旧桌面也生效：旧能力位固定不等于被授权，接纳每条流时复查当前 peer policy；旧 TCP 请求仍只访问该 peer 被允许的具体目标。关闭文件服务时旧文件操作明确拒绝；不因为旧客户端不能理解新能力而开放文件根。

原 TrustedDevice 记录导入来源标为 LegacyImport，不凭空证明旧密码认证；新管理员预置信任为 Administrator。取消使用既有 UserCancelled 代码，旧任务格式仍可读取。当前 P2PD/P2PA 源码相对旧 SHA，经仅路径和可见性规范化后完全一致；这只是静态证据，不替代固定字节或实际旧二进制测试。

T21 测试阶段补全：固定合成身份与旧端构建 SHA；双向发起角色、首流、授权负例、完成/续传、旧数据恢复、不能降级、同身份单登记。未实现的 LegacyCliV3 组合保持不支持，不能为了矩阵通过降低权限。
