Veytrane for Sub2API · Windows x64

适用 Windows 10 / Windows 11 的 64 位电脑。

1. 把 ZIP 完整解压到一个文件夹，不要直接在压缩包内运行。
2. 双击 Start-Sub2API.bat。连接成功后自动打开浏览器。
3. 浏览器地址：http://127.0.0.1:18081/
4. 使用分配给你的 Sub2API 账号登录。

使用时保持命令窗口运行，可以最小化。按 Ctrl+C 或关闭窗口会停止映射。
断线、休眠唤醒或网络变化后，窗口中的程序会自动尝试恢复连接。
如果连接长时间没有进展，程序会自动重建网络并重试，不需要手动重启 Ubuntu 服务。
窗口会显示信令登记、打洞、身份认证和服务就绪等阶段。
如果提示端口 18081 被占用，请关闭已经运行的副本或占用该端口的程序后重试。

无需安装 Python、Rust 或其他运行环境，也无需填写服务器地址、密码或映射规则。
本程序仅提供 Sub2API 入口，不提供通用节点管理页面、文件传输和其他服务配置。
程序不会自动安装开机启动项；需要使用时双击 BAT。

每台电脑的当前 Windows 用户首次启动时会生成自己的身份，保存在：
%LOCALAPPDATA%\Sub2API-Client\identity.key
不要把这个身份文件复制到其他电脑。更新程序时保留此目录即可继续使用原身份。

此分发包包含专用访问凭证，拿到包的人都能连接 Sub2API，请按分发者的要求使用。
